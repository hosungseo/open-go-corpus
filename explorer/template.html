같은 사업이 세 채널에 어떻게 다르게 보이는지, 실물로 본다

사전정보공표는 "이런 정보가 여기 있다"는 안내 목록이고,
원문공개는 결재가 끝난 문서 원본이며,
정책실명제는 사업 하나를 단위로 누가 맡아 어디까지 왔는지 적는 명부입니다.

세 채널은 같은 사업을 서로 다른 단위로 담기 때문에, 이름이 같아도 나오는 것이 다릅니다.
정책실명제 사업 하나를 고르면 같은 이름으로 사전정보공표와 원문공개를 찾은 결과가 나란히 놓입니다.

2025~2026년 사업 개 중 두 채널 어디에서도 찾을 수 없는 사업이 개입니다.

검색어는 사업명에서 자동으로 뽑았다. 출처·표본·한계는 근거·방법에.

예시 사업

실명은 제거하고 직급·역할만 남겼습니다. 2018~2024년 사업은 대조를 수집하지 않아 정책실명제 열만 채워집니다.

각 지표의 각주 번호를 누르면 산출 방법으로 간다.

기관별 등록 현황

연도별 등록 건수. 회색은 그해 등록이 없는 기관. 기관명은 현행 명칭이다. 원문 연결은 2025~2026년 상세를 확인한 사업 중 포털이 관련 원문을 붙여 둔 비율이다.

미등록2026 = 등록 진행 중연결 = 관련원문 있는 사업 / 상세 확인 사업

지자체·교육청 링크 상태

포털에 지자체·교육청 정책실명제 사업 자료 없음. 첫 화면의 외부 링크 개를 열어본 결과다.

수집 방법과 한계

수집 방법

  • 정책실명제 기관 목록 → 기관별 사업 목록(전수) → 상세 페이지(2025~2026)
  • 사전정보공표 '숫자로 보는 정보공개' 통계 + 상세 페이지 표본 + 최근 등록 목록
  • 원문공개 원문공개율 통계(기관유형×연도) + 코퍼스 본문 417건
  • 대조 사업명 검색어 1개로 사전정보·원문을 포털에서 검색

한계

  • 2026년은 등록 진행 중 값. 추세는 2025년까지로 읽을 것
  • 조회수는 내부 확인·봇이 섞일 수 있음
  • 주기·링크 오류율은 표본(100·120·261) 기준
  • 교육청 원문 건수는 각급 학교 포함 포털 표시값
  • "국장급 이상" 범위와 기관당 권고 건수는 구두 확인, 조문·지침 재확인 필요
  • 공공기관 경영공시(ALIO) 항목 대조 미실시
