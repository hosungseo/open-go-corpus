## 최종 설계 상태 (개발자가 그대로 구현)
- 산출물: `explorer/index.html`(단일 파일, 인라인 CSS/JS) + `explorer/data.json`. 라이브러리 없음. 6,847건 클라이언트 필터는 충분히 빠름(한 번 로드 3–4MB).
- 선행: `tools/probe-realname-batch.mjs` 실행 → `realname/probe-batch.json`.
- 빌드: `tools/build-explorer.mjs` → 마스킹·정규화·각주 무결성 → `explorer/data.json`.
- 배포: 1차 아티팩트(비공개 링크). 이후 필요 시 private Pages.
- 화면 4개, 기능 F1–F4, 상태 표시 규칙(빈칸 금지·접기 금지·2026 배지) 전 화면 공통.
