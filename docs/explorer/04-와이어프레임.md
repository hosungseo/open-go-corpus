# Low-fidelity Wireframe — 정보공개 3제도 대조기

시각 문법은 기존 두 아티팩트(정책실명제 AI 구상안·3제도 비교)와 같다: 종이색 바탕, 검정 상단 굵은 선, 세리프 제목, 제도 색(정책실명제 적색·사전정보 황토·원문 청록). 색·장식은 나중.

## 공통 요소
- Header: 이름 + 기준일 + 각주 수. Nav: 4개 고정, 현재 위치 밑줄.
- 숫자는 등폭 숫자(tabular). 제도 색은 열 제목 상단 선으로만.
- 접기·호버·모달 없음. 외부 링크는 ↗ 표기, 새 창.
