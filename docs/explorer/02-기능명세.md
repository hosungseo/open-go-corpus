# 기능명세서 — 정보공개 3제도 대조기

PRD(01)를 개발자가 그대로 구현할 수 있는 수준으로 푼다. 단일 정적 페이지 + JSON. 서버·로그인 없음.

## 공통
- **데이터**: `explorer/data.json` 하나. 빌드 시 `realname/central.jsonl`, `realname/detail.jsonl`, `realname/probe-*.json`, 통계 JSON, 링크 점검 TSV에서 생성. 실명 필드(`chgrNm`, `aprvInfo`의 성명)는 빌드에서 `○○○`로 치환하고 직급·역할만 남긴다.
- **권한**: 열람만. 배포본에는 실명이 없으므로 접근 통제 불필요. 로컬 빌드 `--with-names` 플래그는 배포 금지(스크립트가 파일명에 `.local` 접미사 강제).
- **상태 표시 규칙**: 값이 없으면 빈칸이 아니라 이유를 쓴다 — `포털에 없음`, `대조 미수집`, `등록 진행 중(2026)`.
- **접기 금지**: `<details>`, 호버 툴팁, 클릭해야 보이는 범례 사용 안 함.

## F2. 사업 대조기
| 항목 | 내용 |
|---|---|
| 목적 | 정책실명제 사업 하나를 세 채널에서 동시에 보기 |
| 사용자 행동 | ① 기관 선택(드롭다운) ② 연도 선택(기본 2025) ③ 키워드 입력(선택) ④ 목록에서 사업 클릭 ⑤ 3열 결과 확인 ⑥ URL 복사 |
| 시스템 처리 | 클라이언트에서 `projects[]`를 기관·연도·키워드(사업명·개요 부분일치, 공백 무시)로 필터 → 목록(최대 200, 초과 시 "더 좁히세요") → 선택 시 `gclfCd`로 `detail`·`probe` 조인 → 3열 렌더 → `location.hash = #p=<gclfCd>` |
| 입력값 | `nstCd`, `year`, `q`(문자열), `gclfCd`(해시로도 진입 가능) |
| 출력값 | **열1 정책실명제**: 사업명·기관·담당부서·직급(성명 마스킹)·기간·선정기준(정규화값+원문)·개요·추진배경·추진실적 n건(각 기간·내용·결재선 역할 구조)·관련원문 n건·조회수·등록일·수정일. **열2 사전정보공표**: 검색어, 히트 수, 상위 5건(기관·제목·세부항목 한 줄·주기), 포털 검색 딥링크. **열3 원문공개**: 검색어, 히트 수(기관 한정·기간), 상위 5건(생산일·기관·제목), 관련원문 목록(제목·생산일·결재선 역할 체인 `기안 > 검토 > 협조 > 전결`), 포털 딥링크 |
| 필요한 데이터 | `projects[]`(central.jsonl 정규화), `details{gclfCd}`(prtn, wonmun), `probes{gclfCd}{prev:{kwd,total,items[]}, orginl:{kwd,total,items[]}}`, 기관 코드표 |
| 예외 상황 | 필터 결과 0건 → "해당 조건의 사업 없음. 2026년은 등록 진행 중(7기관)" / 선택 사업에 `probes` 없음 → 열2·3에 `대조 미수집(2018–2024년분)` 배지와 포털 검색 딥링크만 / 히트 0 → `포털에 없음 (검색어 "…")` / 해시의 gclfCd가 없으면 목록 화면으로 복귀하고 안내 / 사업명에 HTML 엔티티·`？` 있으면 빌드에서 복구하되 원문도 보관(`raw_name`) |
| 권한 조건 | 없음. 실명은 데이터에 없음 |

## F3. 기관 현황
| 항목 | 내용 |
|---|---|
| 목적 | 참여·갱신·이용·연결 실태를 기관 단위로 보기 |
| 사용자 행동 | 정렬 기준 선택(2025 건수·조회수 중앙값·원문 연결률·미등록 연수), 기관명 클릭 → F2에 기관 필터 적용 |
| 시스템 처리 | `orgs[]`를 연도×기관 매트릭스로 렌더(셀=건수, 미등록 회색, 2026은 진행 중 표시). 지자체 블록은 링크 점검 결과(상태코드·최종 도착지·실명 문자열 유무)만 |
| 입력값 | `sort`, `nstCd`(해시) |
| 출력값 | 중앙 45기관 × 9연도 매트릭스, 기관별 지표 열, 지자체·교육청 261 링크 상태표(정상/404/오도/타임아웃) |
| 필요한 데이터 | `orgs[]{nstCd,nstNm,years{y:count},median_inq,linked_rate,sampled_n}`, `local_links[]{name,url,status,final_url,has_keyword}` |
| 예외 상황 | 표본 상세가 없는 기관(2018–2024 미샘플)은 연결률 `–`와 각주 / 부처 개편으로 이름이 바뀐 기관은 두 줄로 두고 각주에 계보 |
| 권한 조건 | 없음 |

| 시스템 처리 | ① central/detail/probe/통계/링크 로드 ② HTML 엔티티·`？` 복구, 선정기준 6호 정규화, 기간 정규화 ③ 성명 마스킹(한글 2–4자 + 직급 패턴) ④ note_id 참조 무결성 검사 ⑤ `explorer/data.json` 출력, `--with-names`면 `data.local.json` |
