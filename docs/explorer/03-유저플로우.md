# User Flow — 정보공개 3제도 대조기

## 진입
링크(아티팩트 URL 또는 내부 배포 URL)로 진입. 로그인 없음. 첫 화면은 정지 상태에서 스코어보드 전체와 상단 앵커 6개가 보인다.

```
[진입] ──▶ 화면1 스코어보드 (기준일·각주 번호 함께 노출)
             │
             ├─ (질문형) "물으신 것" 앵커 6개 중 하나 클릭
             │      └─▶ 해당 답 블록으로 스크롤 ─▶ 숫자 클릭 ─▶ 화면4 근거 각주 ─▶ "본문으로" ─▶ 스크린샷 ─▶ 끝
             │
             ├─ (탐색형) "사업 대조기" 클릭 ─▶ 화면2
             │      ├─ 기관 선택 ─▶ 연도 선택(기본 2025) ─▶ [키워드 입력]
             │      │      ├─ 목록 0건 ─▶ 안내("2026은 등록 진행 중 7기관") ─▶ 조건 변경
             │      │      └─ 목록 1–200건 ─▶ 사업 클릭
             │      │              ├─ probe 있음 ─▶ 3열 결과 ─▶ URL 복사/스크린샷 ─▶ 다른 사업 클릭(목록 유지)
             │      │              └─ probe 없음(2018–2024) ─▶ 열1만 채우고 열2·3에 "대조 미수집" + 포털 딥링크
             │      └─ 열1의 기관명 클릭 ─▶ 화면3 해당 기관 행으로
             │
             └─ "기관 현황" 클릭 ─▶ 화면3
                    ├─ 정렬 변경 ─▶ 매트릭스 재정렬
                    ├─ 기관명 클릭 ─▶ 화면2 기관 필터 적용 상태로
                    └─ 지자체 링크 상태표 ─▶ URL 클릭(새 창, 외부)
```

## 재방문
- `#p=<gclfCd>`: 화면2가 해당 사업 3열 상태로 바로 열린다. 존재하지 않는 코드면 목록 화면 + "해당 사업이 스냅샷에 없음(기준일 …)".
- `#org=<nstCd>`: 화면3 해당 기관 행으로 스크롤 + 강조.
- `#n<번호>`: 화면4 각주.

## 분기 조건
| 조건 | 처리 |
|---|---|
| 모바일 폭(<820px) | 3열 → 세로 3블록, 열 제목에 제도 색 유지 |
| 데이터 미수집 | 배지 + 이유 + 포털 딥링크 (빈칸 금지) |
| 2026년 사업 | "등록 진행 중" 배지, 기관 수 7 명시 |
| 부처 개편 기관 | 옛 이름·새 이름 두 행, 각주 |
| 사업명 깨짐 복구 | 복구된 이름 표시, 원문은 작은 글씨로 병기(포털 상태를 증거로 남김) |

## 핵심 기능까지 최단 경로
진입 → "사업 대조기" 클릭 → 기본값(기관 전체·2025) 목록에서 첫 사업 클릭 = **클릭 2회, 3열 도달.** 검색어 입력은 선택.
